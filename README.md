# 🌋 Lava-Rise

Ein schnelles Wortspiel im Browser – ähnlich wie *Type or Die*.

## ▶️ Jetzt spielen
**https://tillwassenhoven1-glitch.github.io/Lava-Rise/**

Keine Installation, kein Konto nötig – läuft auf Handy, iPad und PC. 🎮

## So funktioniert's
- ❓ Eine Frage erscheint, z. B. **„Nenne ein Tier!“**
- ⌨️ Tippe so schnell wie möglich eine passende Antwort
- 🧗 Jeder Buchstabe bringt dich **1 Meter nach oben**
- 🔥 Nach jeder Runde steigt die Lava – immer schneller
- 🏆 Wer als Letztes nicht von der Lava erwischt wird, gewinnt!

## Features
- 🤖 1–5 Bot-Gegner (Leicht / Mittel / Schwer)
- 👀 Antworten werden erst aufgedeckt, wenn alle fertig sind
- 💡 3 Tipps pro Spiel – mit Tipp zählt die Antwort nur halb
- 🇩🇪 🇬🇧 Fragen & Antworten auf Deutsch oder Englisch
- ⏱️ Zeit pro Antwort einstellbar (5–20 Sekunden)
- 🏷️ 10 Kategorien zum An- und Ausschalten (Tiere, Länder, Sport, Städte …)
- ✨ Eigene Kategorie möglich
- 🎉 Party-Modus: jedes Wort zählt
